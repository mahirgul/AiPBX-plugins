# Community plugins

One folder per plugin: `plugins/community/<slug>/` with `plugin.json` at its root and a `README.md`.
See the [main README](../../README.md#-contributing-a-community-plugin) for the rules and
[docs/plugin-development.md](https://github.com/mahirgul/AiPBX/blob/main/docs/plugin-development.md) for the format.
